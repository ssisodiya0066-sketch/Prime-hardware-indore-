# Mobile APK Build

This project includes a GitHub Actions workflow.

After uploading the project files to GitHub:
1. Open the repository.
2. Tap **Actions**.
3. Select **Build Prime Hardware APK**.
4. Tap **Run workflow**.
5. Wait for the build to finish.
6. Open the completed run and download the **Prime-Hardware-APK** artifact.
7. Inside the downloaded artifact, install `app-debug.apk` on Android.

Do not upload passwords, signing keys, or private credentials.
